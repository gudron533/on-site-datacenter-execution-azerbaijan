# Emergency Incident Checklist (On-Site)

1. Confirm incident summary + desired outcome
2. Confirm access method + arrival ETA constraints
3. Confirm hardware identifiers (rack/U position, serial, label)
4. Confirm required tools/parts (if any)
5. Agree communication channel (bridge / ticket / chat)
6. On-site:
   - capture initial state (photos)
   - follow SOP steps
   - capture evidence after each critical action
7. Report:
   - actions taken
   - current state
   - next steps / blockers
