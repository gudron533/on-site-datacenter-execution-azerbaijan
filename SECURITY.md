# Security Policy

This repository is informational and does not contain production software.
However, if you believe you have found a security issue that affects any related systems or public endpoints, please report it responsibly.

## Reporting a vulnerability

Please email: **ruslan@seyidov.az**

Include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Impact assessment (what could happen)
- Any relevant screenshots/logs
- Your contact details for follow-up

## Response expectations

- I will acknowledge receipt as soon as possible.
- If the report is valid, I will work to address it and coordinate disclosure when appropriate.

## Scope

In scope:
- Public website endpoints related to `seyidov.az` (if applicable)
- Any public-facing assets explicitly linked from this repository

Out of scope:
- Denial of service (DoS) testing
- Social engineering
- Physical security testing
- Issues that require unauthorized access

Thank you for helping keep things safe.
